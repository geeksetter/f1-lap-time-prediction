# Требования учебной практики

Сверено с предоставленным пособием «Учебная практика 2027», страницы 6, 8–10. Сам PDF в публичный репозиторий не включён.

| Требование | Компонент | Статус |
|---|---|---|
| Источник, метод и процедура сбора | README, api.py, collect.py | Этап 1 |
| Структура, типы и единицы | database.md, SQL DDL | Этап 1 |
| База, связи, ключи, SQL | PostgreSQL, 001_schema.sql | Этап 1 |
| ER-скриншот из DBeaver | Инструкция подключения в README | Пользователь должен сохранить скриншот; пока есть Mermaid |
| Число записей, пропуски, описательные статистики и частоты | quality.json, quality.md | Этап 1 |
| Минимум четыре типа диаграмм | eda.md, 02_preparation_eda.ipynb: гистограмма, линия, boxplot, scatter | Этап 2, выполнено |
| Множественная линейная регрессия | regression.py: собственный класс, SVD, fit/predict/save/load | Этап 3, выполнено |
| MAE, RMSE, R², скорректированный R² | metrics.py, reports/modeling; adjusted R² только при применимости | Этап 3, выполнено |
| Текст отчёта, введение, заключение, оформление | План четвёртой части | Следующий этап |

Уточнения пользователя строже общих рекомендаций пособия: PostgreSQL, обязательное чтение данных через SQL, собственная модель на ООП вместо оболочки над библиотекой, GitHub.

Разбиение 70/30 или 80/20 в пособии является рекомендацией. Для временной задачи предполагается разбиение по гонкам и хронологии; обоснование будет приведено в отчёте. Утверждение темы и источника преподавателем остаётся организационным требованием пособия и не заявляется здесь как выполненное.
