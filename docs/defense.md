# Материалы для защиты

Тема: «Анализ и прогнозирование времени прохождения круга в гонках Формулы-1 с учётом характеристик шин и погодных условий».

## Короткое выступление

Работа посвящена прогнозу времени одного обычного сухого круга до его начала. Для сопоставимости выбрана одна трасса Catalunya и три гонки 2023–2025. Данные получены автоматически через OpenF1, сохранены в PostgreSQL вместе с исходными JSON и происхождением запросов. Собрано 3826 кругов; после прозрачного отбора осталось 3362.

Каждый круг связан с пилотом, сессией и отрезком на шинах. Пробег шин рассчитывается на начало круга. Погода берётся из последнего предыдущего замера. Сектора текущего круга, будущая погода и последующие события не подаются модели. Все исключения сохраняются отдельно от исходных данных. Подготовка и обучение читают таблицы через SQL.

Собственный класс множественной линейной регрессии использует SVD-псевдообратную NumPy. Я реализовал свободный член, проверки входа, обучение, прогноз, сохранение и загрузку. Кодирование категорий и масштабирование обучаются только на тренировочной части. Математический тест с известной формулой даёт ошибку порядка 10⁻¹⁵.

Разбиение хронологическое: 2023 для обучения, 2024 для выбора признаков, 2025 для итогового теста. По валидации выбран набор с составом и пробегом шин. На тесте его MAE составляет 0.8525 секунды, RMSE — 1.1262, R² — 0.3806. Среднее последних корректных кругов точнее: MAE 0.6576 секунды. Поэтому вывод работы — полный воспроизводимый пайплайн и проверенная собственная модель с честным сравнением; превосходство над сильным базовым прогнозом не достигнуто.

Три гонки ограничивают обобщение. Температуры 2025 находятся вне тренировочных диапазонов; есть новые пилоты. Связи шин и температуры с временем описательные, причинный эффект не установлен. Для улучшений потребуется новая заранее выделенная гонка, чтобы не подбирать модель под уже изученный тест.

## Признаки и доступность

| Признак | Источник | Что известно к началу круга |
|---|---|---|
| Имя пилота | drivers | Участник текущей сессии |
| Номер круга | laps | Пройденное число кругов и следующий номер |
| Состав шин | stints | Установленный комплект; предполагается знание командой |
| Пробег до круга | stints + номер | `tyre_age_at_start + lap_number - lap_start` |
| Температуры воздуха/трассы, °C | weather | Последний замер с timestamp не позже старта |
| История для базовых прогнозов, с | training_laps | Уже завершённые прошлые принятые круги той же пары пилот/сессия |

Состав и пробег входят в выбранную регрессию; температуры проверены отдельным набором. История используется в базовых методах, не в этих трёх регрессиях. Target `lap_duration` становится известен после завершения прогнозируемого круга. Доступность состава предполагается по знанию команды; historical API не содержит timestamp объявления stint. Фактические задержки сообщений live API не проверены.

## Почему круги исключаются

Первый круг связан со стартом. Pit-in/out и круги под ограничениями race control отличаются от обычного темпа. Дождь и дождевые шины выходят за сухую область. Отсутствующая цель или время начала не восстанавливаются догадками. Широкие физические проверки выявляют невалидные обязательные значения. Медленные, но валидные обычные круги сохраняются. Каждый круг имеет массив всех причин; 464 исключения — число строк, а не сумма причин.

SC/VSC, pit-in, флаги и дождь во время круга могут стать известны только после старта. Они служат ретроспективной разметкой области оценки, а не входом модели. Поэтому результат относится к выбранному условному классу кругов.

## Ответы на вероятные вопросы

**Почему Формула-1 полезна для учебного проекта?** Она позволяет показать сложные временные соединения, работу с реальным API, реляционную БД, ООП и проверку ML. Это учебная аналитика, а не заявка на готовую стратегию команды.

**Почему одна трасса?** Разные трассы имеют разные длины, конфигурации и уровни темпа. Ограничение уменьшает число смешивающих различий и делает первую модель объяснимой. Перенос на другие трассы не проверен.

**Почему только три гонки, если кругов тысячи?** Это доступные завершённые сезоны выбранного периода для этой трассы. Круги зависимы; независимых погодных сценариев мало. Тысячи строк не равны тысячам независимых экспериментов.

**Что значит tyre_age_at_start?** Завершённые круги комплекта до начала stint. На первом круге stint добавляется ноль. Физический износ непосредственно не измеряется.

**Почему нельзя соединить погоду по ближайшему времени?** Ближайшая запись может быть будущей. Используется только последняя запись `date <= lap_start_at` в той же сессии, и timestamp сохраняется для аудита.

**Почему не случайные 80/20?** Случайное разбиение смешает соседние круги в одинаковых условиях. Цель — перенос на более позднюю гонку; поэтому целые гонки разделены хронологически. Рекомендованная доля не важнее корректного момента прогноза.

**Модель действительно собственная?** Да, вычисление коэффициентов, свободный член, проверки и сериализация реализованы в классе. NumPy выполняет SVD; sklearn-регрессия не вызывается.

**Почему SVD?** Псевдообратная устойчивее явного обращения XᵀX и определяет минимальную норму при вырожденности. Численный порог и ранг сохраняются.

**Что происходит с новым пилотом?** Центрированные категориальные индикаторы равны нулю; применяется средний тренировочный эффект. На тесте это затрагивает 317 кругов и ограничивает точность.

**Что происходит при нехватке прошлых кругов?** Среднее 1–2 доступных времён; если истории нет, заранее сохранённое среднее fit-целей. Такие 35 тестовых строк не исключаются из сравнения.

**Использование прошлых тестовых целей — утечка?** При последовательном прогнозе они уже завершены и известны до следующего круга. SQL проверяет время окончания и принадлежность пилоту/сессии. Предсказать всю гонку до старта этим способом нельзя.

**Почему погода не помогла?** В этом эксперименте она не улучшила валидацию и тест относительно шин. Все тестовые температуры лежат за fit-диапазонами. Данных недостаточно, чтобы объявить погоду бесполезной вообще.

**Как читать коэффициент пробега?** В выбранной fit-модели +1 завершённый круг шин связан примерно с +0.07038 с при прочих фиксированных входах. Номер круга связан с −0.05518 с. Это условные линейные связи, не причинная деградация и не измеренное влияние топлива.

**Почему регрессия хуже простой базы?** История отражает текущий темп пилота и ненаблюдаемые условия. Регрессия учит средние связи прошлых гонок и хуже переносит новый сценарий. Неудачное сравнение сохранено и объяснено, а не скрыто.

**Где adjusted R²?** Для полного fit-набора выбранной OLS: 0.6996 при n=2373, p=24, ранг 25/25. Для теста эта in-sample поправка не применяется.

**Может ли MAE скрывать большие ошибки?** Да. Поэтому приведены RMSE, остатки и ошибки по группам с n. Крупные ошибки сохранены; причины отдельных замедлений без подтверждения не придумываются.

**Как повторить результат?** Запустить команды README с новым PostgreSQL и `.local/experiment`. Проверка запуска с пустой БД и новой venv записана в `reports/final_verification.json`.

**Что ещё требуется для сдачи?** Заполнить реквизиты, приложить кафедральные формы и подписи, получить скриншот DBeaver, согласовать тему и оформление с преподавателем. Проект не заменяет эти организационные действия.

## Скриншот DBeaver

1. Создать соединение PostgreSQL: host `127.0.0.1`, port из `.env` (обычно 55432), database `f1_project`, user `f1`. Пароль брать локально из `.env`; не помещать его на скриншот.
2. Открыть schema `f1`, выбрать основные таблицы meetings, sessions, drivers, laps, stints, weather, race_control. Открыть ER Diagram и показать связи.
3. Получить второй вид для `analytics`: preparation_runs, lap_observations, training_laps. При необходимости включить связи с f1.laps.
4. Сохранить читаемые скриншоты в `docs/figures/dbeaver_raw.png` и `dbeaver_analytics.png`, добавить их в отчёт с подписью «ER-диаграмма из DBeaver». Закрыть диалог соединения до снимка.

В текущей поставке есть Mermaid и DDL; реальные снимки DBeaver не приложены, поскольку управление приложением было отклонено. Не подменять их иллюстрацией другого инструмента.
