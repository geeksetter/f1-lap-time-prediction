# Происхождение данных и использование

Данные получены через [OpenF1 API](https://openf1.org/docs/) из семи endpoints для испанских Race-сессий 9102, 9539, 9971 за 2023–2025. OpenF1 создан br-g и участниками проекта; [репозиторий провайдера](https://github.com/br-g/openf1). Проект не аффилирован с Formula 1, FIA или командами; права на товарные знаки не передаются.

Проверено 14.10.2026: файл [LICENSE провайдера](https://github.com/br-g/openf1/blob/87540e3f495bbd9bedb37b10456dd848c8f193d6/LICENSE) содержит **CC BY-NC-SA 4.0**. Условия включают атрибуцию, некоммерческое использование и распространение адаптаций на тех же условиях. [Краткое изложение](https://creativecommons.org/licenses/by-nc-sa/4.0/), [полный текст](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode).

Лицензия репозитория OpenF1 и бесплатный доступ к историческому API не подтверждают передачу всех прав третьих лиц на спортивные данные. Здесь не заявляется безусловное право коммерческой перепродажи данных. Код проекта разработан самостоятельно; код OpenF1 не копировался. [MIT](LICENSE) относится только к собственному коду и SQL, а не к данным провайдера.

Изменения данных в этой работе: нормализация типов и UTC, соединение кругов с шинами и прошлой погодой, отбор обычных сухих кругов, расчёт признаков, обучение и оценка. Производные таблицы прогнозов, модели, графики, отчёты и результаты ноутбуков в `artifacts/`, `reports/`, `notebooks/` и `docs/practice_report.*` распространяются в части прав автора под **CC BY-NC-SA 4.0**, со ссылкой на OpenF1 и указанием этих преобразований. Данные и результаты предоставлены без гарантий точности; условия провайдера и права третьих лиц сохраняются.

Полные ответы API и исходные JSON хранятся только локально в PostgreSQL с URL, параметрами, временем получения, SHA-256 и ID загрузки. В Git нет дампа БД, полного архива API, изображений пилотов, логотипов или видео. Небольшие CSV содержат производные признаки, прогнозы и временные следы для аудита опубликованных метрик, а не используются как вход обучения. Происхождение конкретного расчёта указано в `artifacts/stage3/manifest.json` и отчётах проверки.
